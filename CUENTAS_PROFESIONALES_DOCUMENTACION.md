## 🔐 SEGURIDAD Y VALIDACIONES

- Formato: Numérico
- No se muestra en pantalla por seguridad
- Requerido para todas las operaciones

- Cuenta debe estar activa
- PIN debe coincidir exactamente

## 🚀 CÓMO USAR LAS CUENTAS

### **Paso 1: Acceder al Login**
1. Abre la aplicación
2. Ve a la página de login (sin cuentas de prueba visibles)
3. Ingresa el número de cuenta (ej: `412087654321`)
4. Ingresa el PIN (ej: `8475`)

### **Paso 2: Menú Principal**
Después de iniciar sesión verás:
- ✅ Tu nombre completo
- ✅ Tipo de cuenta (Corriente/Ahorro)
- ✅ Opciones de operaciones

### **Paso 3: Ver Detalles de Cuenta**
1. Click en "Mi Cuenta" (🪪)
2. Visualiza:
   - Tarjeta visual de la cuenta
   - Número de cuenta
   - Fecha de creación
   - Fecha de expiración
   - PIN (oculto por seguridad)
   - Saldo actual
   - Límites de tu cuenta

## 🔧 CONFIGURACIÓN DEL SISTEMA

Las cuentas están configuradas en:
**Archivo:** `Cajero.Core\Repositories\RepositorioCuenta.cs`

```csharp
new Cuenta 
{ 
    Id = 1, 
    NumeroCuenta = "412087654321", 
    Propietario = "Juan García López", 
    PIN = "8475", 
    Saldo = 15750.50m,
    TipoCuenta = TipoCuentaEnum.Corriente,
    Activa = true,
    FechaCreacion = new DateTime(2022, 3, 15)
}
```

---

## 📝 NOTAS IMPORTANTES

1. **Seguridad:** Los PINs no se muestran en la pantalla de detalles
2. **Realismo:** Los números de cuenta son formato estándar bancario
3. **Flexibilidad:** Puedes agregar más cuentas siguiendo el mismo patrón
4. **Persistencia:** Las cuentas se reinician cuando se reinicia la aplicación
5. **Actualización:** Los saldos se actualizan en tiempo real con cada operación

## 🎓 INFORMACIÓN ADICIONAL

### Cómo Agregar Nueva Cuenta
En el archivo `RepositorioCuenta.cs`, agrega un nuevo objeto `Cuenta`:

```csharp
new Cuenta 
{ 
    Id = 4, 
    NumeroCuenta = "412087654324", 
    Propietario = "Tu Nombre", 
    PIN = "1234", 
    Saldo = 50000m,
    TipoCuenta = TipoCuentaEnum.Ahorro,
    Activa = true,
    FechaCreacion = DateTime.Now
}
```

## 📞 SOPORTE

Para cambiar información de cuentas:
1. Edita `Cajero.Core\Repositories\RepositorioCuenta.cs`
2. Modifica los datos en el método `InicializarDatos()`
3. Reconstruye la aplicación
4. Los cambios serán aplicados al reiniciar
