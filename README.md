# 💰 Sistema Cajero 2026

Aplicación de Gestión Bancaria en .NET 10

## Descripción

Sistema Cajero 2026 es una aplicación completa de gestión bancaria desarrollada en ASP.NET Core MVC con .NET 10.

## Características

- ✅ Autenticación segura con PIN
- ✅ Operaciones bancarias (Retiro, Depósito, Transferencia)
- ✅ Gestión de transacciones
- ✅ Comprobantes automáticos
- ✅ Validaciones completas
- ✅ 3 interfaces (Web MVC, Consola CLI, Backend Core)

## Requisitos

- .NET 10 SDK o superior
- Visual Studio 2022/2026

## Instalación

`
git clone https://github.com/kevin-figueroa10/Sistema_Cajero_2026.git
cd "Sistema Cajero"
dotnet restore
dotnet build
`

## Uso

### Web
`
cd Cajero.Web
dotnet run
`

### Consola
`
cd Cajero.Consola
dotnet run
`
